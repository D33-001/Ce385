ex1-profile.js
--------------------------------------------------
สิ่งที่ทำ:

ex2-types.js
--------------------------------------------------
สิ่งที่ทำ:
ส่วนที่ 1 - สร้างตัวแปรให้ครบ 6 ชนิดข้อมูล แล้วใช้ typeof ตรวจสอบชนิด
  - string, number, boolean, undefined, null, array (object)

ส่วนที่ 2 - ตอบคำถามด้วยโค้ดจริง (ทดลองแล้วอธิบายผล)
  - typeof null ได้ผลเป็น "object" (บั๊กเก่าแก่ของภาษา JavaScript
    ที่แก้ไม่ได้เพราะจะทำเว็บเก่าพัง)
  - ตัวแปรที่ประกาศแล้วยังไม่ใส่ค่า จะมีชนิดเป็น "undefined" โดยอัตโนมัติ
  - typeof NaN ได้ผลเป็น "number" (แม้ NaN จะแปลว่า "ไม่ใช่ตัวเลข" ก็ตาม)

ส่วนที่ 3 - การแปลงชนิดข้อมูล (Type Conversion)
  - แปลง string เป็น number ด้วย Number() ก่อนนำไปคำนวณ เพื่อไม่ให้
    เกิดปัญหาการต่อข้อความ (string concatenation) แทนการบวกเลข
  - ใช้ .toFixed(1) จัดทศนิยม
  - เปรียบเทียบ === (Strict Equality) แสดงให้เห็นว่า string "20"
    ไม่เท่ากับ number 20 จนกว่าจะแปลงชนิดให้ตรงกันก่อน

ex3-calculator.js
--------------------------------------------------
สิ่งที่ทำ:
- ประกาศค่าคงที่ (constants) ของเกณฑ์การให้คะแนนไว้ด้านบน เช่น
  คะแนนดิบเต็มของ Workshop, สัดส่วนคะแนน Workshop, คะแนนเต็มรวม,
  คะแนนเป้าหมาย (ไม่ใช้ตัวเลขดิบแทรกกลางสูตรตามกฎวิชา)
- เก็บคะแนนดิบแต่ละส่วน (workshop, เข้าห้องเรียน, โปรเจกต์, กลางภาค,
  ปลายภาค)
- แปลงคะแนน Workshop ด้วยวิธีบัญญัติไตรยางศ์ (คะแนนดิบ/คะแนนเต็ม
  x น้ำหนักคะแนน)
- รวมคะแนนทั้งหมด คำนวณเปอร์เซ็นต์ และคำนวณว่าขาดอีกกี่คะแนนถึงจะ
  ได้เกรด A (80 คะแนน)
- แสดงผลเป็นใบสรุปคะแนนด้วย Template Literal โดยใช้ .toFixed(2)
  ตอนแสดงผลเท่านั้น (ไม่ใช้ตอนคำนวณ เพื่อป้องกันความคลาดเคลื่อน)

ex4-grade.js
--------------------------------------------------
สิ่งที่ทำ:
- เขียนฟังก์ชัน toGrade(score) ที่รับคะแนนเข้ามา
- ตรวจสอบความถูกต้องของข้อมูลก่อนเสมอ (Data Validation) ถ้าคะแนน
  ติดลบหรือเกิน 100 จะแจ้งว่า "คะแนนไม่ถูกต้อง"
- ใช้ if/else if ตัดเกรดตามช่วงคะแนน (A, B+, B, C+, C, D+, D, F)
  โดยต้องเรียงเงื่อนไข "จากมากไปน้อย" เสมอ เพราะ if/else if จะหยุด
  ทำงานที่เงื่อนไขแรกที่เป็นจริง
- ทดสอบฟังก์ชันด้วยคะแนนหลายค่า (รวมค่าผิดปกติอย่างติดลบและเกิน 100)
  โดยใช้ for...of วนลูปอาร์เรย์คะแนนทดสอบ แล้วพิมพ์ผลลัพธ์ทีละค่า

ex5-switch.js
--------------------------------------------------
สิ่งที่ทำ:
- ฟังก์ชัน getMenuPrice(menu) หาราคาอาหารตามชื่อเมนู โดยใช้ switch
  และตั้งใจใช้ fall-through (case ต่อกันไม่มี break คั่น) รวมเมนูที่
  ราคาเท่ากันไว้ด้วยกัน
- ฟังก์ชัน getSizeMultiplier(size) หาตัวคูณราคาตามขนาด (ธรรมดา/
  พิเศษ/จัมโบ้)
- มี default ในทุก switch เผื่อกรณีเมนูหรือขนาดที่ไม่มีในระบบ
- สร้างอาร์เรย์ orders จำลองรายการอาหารที่ลูกค้าสั่ง (รวมเมนูที่ไม่มี
  ในระบบไว้ทดสอบ default ด้วย)
- วนลูปคำนวณราคาแต่ละรายการ (ราคาพื้นฐาน x ตัวคูณขนาด x จำนวน)
  แล้วสะสมเป็นยอดรวมทั้งบิล พิมพ์รายการและยอดรวมออกมา

ex6-login.js
--------------------------------------------------
สิ่งที่ทำ:
- เขียนฟังก์ชัน login(inputUser, inputPass, role, isActive, age)
  ตรวจสอบสิทธิ์ตามลำดับขั้นตอนดังนี้:
  1. ตรวจ username/password ก่อนเสมอ (Authentication) ถ้าผิดจะตอบ
     กลับแบบกำกวมว่า "ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง" เท่านั้น
  2. ตรวจว่าบัญชีถูกระงับหรือไม่
  3. ตรวจอายุว่าถึงเกณฑ์หรือไม่ (18 ปีขึ้นไป)
  4. ตรวจ role ว่าเป็นอาจารย์ นักศึกษา หรืออื่นๆ (ดักข้อมูลแปลกปลอม
     ด้วย else สุดท้าย)
- ทดสอบการทำงาน 6 กรณี ครอบคลุมทั้งสำเร็จและผิดพลาดทุกแบบ (รหัสผ่านผิด,
  ชื่อผู้ใช้ผิด, บัญชีถูกระงับ, อายุไม่ถึง)
- ตอบคำถามท้ายข้อ (เขียนเป็นคอมเมนต์) อธิบายว่า:
  - ทำไมต้องตรวจ username/password ก่อนตรวจ role เสมอ เพราะต้องทำ
    Authentication (ยืนยันตัวตน) ก่อน Authorization (ตรวจสิทธิ์)
  - ถ้าตรวจอายุก่อนจะเกิดปัญหา Information Leakage เพราะแฮกเกอร์
    จะรู้ได้ว่า username นั้นมีอยู่จริงในระบบ

==================================================
สรุปภาพรวมทั้งหมด
==================================================
งานทั้ง 6 ไฟล์นี้เป็นการฝึกพื้นฐาน JavaScript ตั้งแต่:
- การประกาศตัวแปร (const/let) และชนิดข้อมูล
- การแปลงชนิดข้อมูลและการเปรียบเทียบค่า
- การคำนวณและจัดรูปแบบตัวเลข
- การเขียนฟังก์ชันและเงื่อนไข if/else, switch-case
- การวนลูปด้วย for...of
- การออกแบบระบบง่ายๆ ที่คำนึงถึงความปลอดภัย (validation และ
  authentication/authorization)
